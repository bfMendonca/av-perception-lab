# Task 0031: Rename the project to av-perception-lab (COMPLETED)

## Description

The project started as a small "detector + depth → distance" script and was
named after that recipe (`det-depth-distance`). It is now a perception test
bed for autonomous driving: pluggable detectors, metric depth, semantic and
lane segmentation, tracking and motion prediction, camera calibration,
evaluation against field references and a web interface to compare runs.
The name no longer describes it.

This task renames it to **av-perception-lab**:

| Where | Old | New |
|---|---|---|
| Python package | `det_depth_distance` | `av_perception_lab` |
| Distribution (`pyproject.toml`, `uv.lock`) | `det-depth-distance` | `av-perception-lab` |
| Console scripts | `det-depth-distance`, `-calibrate`, `-evaluate`, `-web` | `av-perception-lab`, `-calibrate`, `-evaluate`, `-web` |
| Environment variables | `DDD_*` (`DDD_WEIGHTS_ROOT`, `DDD_UV`, ...) | `AVPL_*` |
| Front-end package (`web/package.json`) | `det-depth-distance-web` | `av-perception-lab-web` |
| Positioning text | "per-object distance to the camera" | perception test bed for autonomous driving |

`git mv src/det_depth_distance src/av_perception_lab`, then replace the three

### Step 2: Regenerate the lock and reinstall

Rewrite the project summary in `README.md`, `DESCRIPTION.md`, `CITATION.cff`
and the `pyproject.toml` description (perception test bed for autonomous
driving; distance is one of its measurements).

with Implementation details and Test notebook.

## Impact Analysis

| A leftover old name breaks an import or a command | Medium | `grep` for the three spellings after the rewrite (only historical docs may match); full test suites |
| Users' environments keep `DDD_*` set and the code ignores it silently | Medium | List the renamed variables in the CHANGELOG migration note; no compatibility alias (the project is a research prototype with no external users) |
